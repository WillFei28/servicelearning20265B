# 鐵路平交道模擬（穩定版）

`main` 是穩定參考。接線、行為同程式以這份說明同 `src/main.cpp` 為準。

六個組別 branch 由這個版本開出，起點同 `main` 一樣：

- `gp1`
- `gp2`
- `gp3`
- `gp4`
- `gp5`
- `gp6`

組別可以換下面三個音效。換完之後，腳位同行為仍然睇 `main` 這份 README。

板：ESP32-WROOM-32 38-pin，插在 Goouuu ESP32S 38P 擴展板。  
上傳線插 **ESP32 模組本身的 Micro-USB**。擴展板的 USB 同 DC 座只供電，傳唔到程式。

## 而家點運作

開機時附近唔好有磁鐵。程式會記住 7 粒霍爾傳感器各自的靜止電壓。

某一粒同自己的靜止電壓相差 **250 mV** 或以上就算有磁鐵：

- 電壓下跌是 **N**
- 電壓上升是 **S**

| 情況 | 燈帶（GPIO18 MOSFET） | 舵機 SG90 | OLED | 喇叭 |
| --- | --- | --- | --- | --- |
| 無磁鐵 | 熄 | 0° | 空白 | 停 |
| 有 N | 長亮。有 N 就優先過 S | 睇有無 S | 大剔號 | 停，除非同時有 S |
| 有 S | 每秒閃 2 下 | 180° | 大交叉 | 循環播平交道聲 |
| N 同 S 一齊 | 長亮 | 180° | 交叉同剔號一齊 | 循環播平交道聲 |

最近一次有效的 N 或 S 會記住，磁鐵拿走都保留。拍 RFID 卡就用這筆記錄，用完即刻清走。清走之後，要先回到無磁鐵，先可以再記新一次。

| 記住的極 | 畫面（至少約 2.2 秒；聲音更長就播完先收） | 聲音 |
| --- | --- | --- |
| N | `+$2.0` | `audio/octopus.mp3` |
| S | `-$2.0` | `audio/error.mp3` |
| 無記錄 | 無車費畫面 | 無聲 |

幾粒同時有磁鐵時，車費記錄用相差最大的那一粒。

## 接線

擴展板跳線撥在 **5V**。每一列紅色針都是 5V，黑色針是 GND，黃色針先是 GPIO。

紅色 5V 唔好接 RC522、74HC4051 或 49E。

### 燈帶 MOSFET

| 位置 | 接到 |
| --- | --- |
| PWM 信號 | P18 黃色（GPIO18） |
| 模組 `+` | P18 紅色 5V |
| 模組 GND | P18 黑色 GND |
| 模組 `−` | P19 黑色 GND |
| 燈帶黑色 | 模組 LOAD |
| 燈帶紅色 | P19 紅色 5V |

P19 黃色（GPIO19）冇用。N 長亮，S 每秒閃 2 下，無磁鐵熄滅。

### 74HC4051 同 7 粒 49E

`Y7` 留空。七粒 49E 的 OUT 接 Y0–Y6。49E 的 VCC、GND 同 4051 一齊取電，唔接擴展板。有字一面向外。

| 74HC4051 | 接到 |
| --- | --- |
| S0 | P12 黃色（GPIO12） |
| S1 | P14 黃色（GPIO14） |
| S2 | P27 黃色（GPIO27） |
| Z | P13 黃色（GPIO13） |
| E | P27 黑色 GND |
| VCC | 最邊的 3.3V |
| VEE | 最邊 3.3V 下面的黑色 GND |
| GND | SD2 黑色 GND |
| 49E VCC | 同 VCC 一樣的 3.3V |
| 49E GND | 同 GND 一樣 |

VEE 是負電源，必須接地。接到 3.3V 會反接電源。

### SG90 舵機

三條線插在 P32 同一列。

| SG90 | 接到 |
| --- | --- |
| 黃（信號） | P32 黃色（GPIO32） |
| 紅 | P32 紅色 5V |
| 黑 | P32 黑色 GND |

有 S 去 180°，無 S 返 0°。P34、P35 只可以輸入，唔可以做舵機信號。

### MAX98357A 喇叭

`GAIN` 同 `SD` 留空。

| MAX98357A | 接到 |
| --- | --- |
| LRC | P17 黃色（GPIO17） |
| BCLK | P16 黃色（GPIO16） |
| DIN | P4 黃色（GPIO4） |
| VIN | P4 紅色 5V |
| GND | P4 黑色 GND |
| 喇叭兩端 | 模組的喇叭端子 |

### 0.96 吋 SSD1306（128×64，I2C 位址 0x3C）

接法不變。程式用 `Wire.begin(22, 21)`。

| OLED | 擴展板 |
| --- | --- |
| VCC | VCC |
| GND | GND |
| SCL | D21（GPIO21） |
| SDA | D22（GPIO22） |

### RC522 RFID

**只可以接 3.3V。** `IRQ` 同 P35 留空。

P34 同 P35 都只入唔出。讀卡器要四個輸出（SDA、SCK、MOSI、RST），呢五隻腳入面只得 P33、P25、P26 出得到信號。所以 MISO 用 P34，RST 直接接 3.3V，P35 唔用。

| RC522 | 接到 |
| --- | --- |
| 3.3V | 板靠中的 3.3V |
| GND | 該 3.3V 下面的黑色 GND |
| RST | 同一粒 3.3V |
| SDA / SS | P26 黃色（GPIO26） |
| SCK | P33 黃色（GPIO33） |
| MOSI | P25 黃色（GPIO25） |
| MISO | P34 黃色（GPIO34） |

## 三個音效可以換

建置前 `embed_crossing.py` 會把這三個檔寫進程式。唔好手改 `src/crossing_mp3.h`，那個檔每次編譯會重新產生，亦唔會入 git。

| 檔案 | 何時播 | 而家大小 |
| --- | --- | --- |
| `audio/crossing.mp3` | 有 S 就循環播 | 50782 bytes |
| `audio/error.mp3` | 拍卡，記錄是 S | 24451 bytes |
| `audio/octopus.mp3` | 拍卡，記錄是 N | 24450 bytes |

換檔時：

1. 檔名保持 `crossing.mp3`、`error.mp3`、`octopus.mp3`。
2. 用普通 MP3。三個檔聲量盡量接近，太細會聽唔到。
3. 檔案開頭唔好帶 ID3 封面或標籤。而家三個穩定檔一開始就是 MP3 音訊框（`FF FB`）。前面如果有標籤，拍卡聲會慢一拍。
4. 只改自己組別的 branch，唔好直接改 `main`。

換完之後在專案資料夾上傳：

```bash
git checkout gp1
pio run -t upload --upload-port 上次成功的USB埠
```

`gp1` 換成自己的組別。Mac 上列出埠：

```bash
ls /dev/cu.usb*
```

序列埠監視是 115200。開機應見到 `Calibrating. Keep magnets away.`，以及每粒傳感器的靜止電壓。

## 穩定程式

行為同腳位常數在 `src/main.cpp` 開頭。PlatformIO 環境是 `esp32dev`，`espressif32@7.1.3`，Arduino framework。上傳速率 921600。
