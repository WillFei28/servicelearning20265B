# Gp5 鐵路平交道

這份是 `gp5`。只接下面的零件，腳位跟這份，唔好抄另一組或 `main`。

板：ESP32-WROOM-32 38-pin，插在 Goouuu ESP32S 38P 擴展板。  
上傳線插 **ESP32 模組本身的 Micro-USB**。擴展板的 USB 同 DC 座只供電，傳唔到程式。

程式由六組共用版本改出來：燈改做兩粒 LED，兩隻舵機反向郁。這組接霍爾、兩粒 LED 同兩隻舵機。沒有接的喇叭、畫面、讀卡器不會動。序列埠仍可能印 `snd` 或 `card`。

## 零件

| 零件 | 數量 | 備註 |
| --- | --- | --- |
| ESP32-WROOM-32 38-pin | 1 | 已插在擴展板 |
| Goouuu ESP32S 38P 擴展板 | 1 | 跳線撥在 5V |
| 74HC4051 | 1 | Y7 留空 |
| 49E | 7 | OUT 接 Y0–Y6 |
| 5V LED（內置電阻） | 2 | 紅線接 P18、P19 黃色，黑線接 GND |
| SG90 | 2 | R23 同 P5，兩隻反向郁 |
| 杜邦線 | 若干 | |

這組沒有：MOSFET 燈帶模組、燈帶、MAX98357A、RC522、OLED、第 8 粒 49E、18650。

兩隻 SG90 一齊郁嗰陣電流大。只靠電腦 USB 可能令 ESP32 重啟。零件表沒有 18650，5V 供電要夠電流。

## 這組點運作

開機時附近唔好有磁鐵。程式記住 7 粒霍爾各自的靜止電壓。某一粒同自己的靜止電壓相差 **250 mV** 或以上就算有磁鐵：電壓下跌是 **N**，電壓上升是 **S**。

| 情況 | 兩粒 LED（GPIO18 + GPIO19） | 兩隻 SG90（A / B） |
| --- | --- | --- |
| 無磁鐵 | 熄 | 0° / 180° |
| 有 N | 長亮。有 N 就優先過 S | 睇有無 S |
| 有 S | 每秒閃 2 下 | 180° / 0° |
| N 同 S 一齊 | 長亮 | 180° / 0° |

## 接線

擴展板跳線撥在 **5V**。每一列紅色針都是 5V，黑色針是 GND，黃色針先是 GPIO。

紅色 5V 唔好接 74HC4051 或 49E。

### 兩粒 5V LED

兩粒 LED 各自內置電阻，唔使另外加電阻。紅線接 GPIO 黃色針，黑線接黑色 GND。

| LED | 紅線 | 黑線 |
| --- | --- | --- |
| LED 1 | P18 黃色（GPIO18） | P18 黑色 GND |
| LED 2 | P19 黃色（GPIO19） | P19 黑色 GND |

唔好接紅色 5V 針：5V 倒灌會燒 ESP32 腳。3.3V 推會比 5V 暗啲。N 長亮，S 每秒閃 2 下，無磁鐵熄滅。

### 74HC4051 同 7 粒 49E

`Y7` 留空。七粒 49E 的 OUT 接 Y0–Y6。有字一面向外。

| 74HC4051 | 接到 |
| --- | --- |
| S0 | P12 黃色（GPIO12） |
| S1 | P14 黃色（GPIO14） |
| S2 | P27 黃色（GPIO27） |
| Z | P35 黃色（GPIO35） |
| E | P27 黑色 GND |
| VCC | 最邊的 3.3V |
| VEE | 最邊 3.3V 下面的黑色 GND |
| GND | SD2 黑色 GND |

VEE 是負電源，必須接地。接到 3.3V 會反接電源。靠中那粒 3.3V 這組留空。

49E 供電，兩種都可以：

- VCC 由 4051 的 VCC 腳取出，GND 由 4051 的 GND 腳取出。
- 擴展板不夠位、要由另一塊板取 3.3V 和 GND：另一塊板的 GND 必須接到 4051 的 GND（SD2 黑色）。只共地。不要把兩塊板的 3.3V 並在一起。

沒有磁石時，每粒應停在大約 1500–1700 mV。讀數在 0 和 3300 mV 之間滑，是地線未共。

### SG90 舵機

兩隻反向郁，一隻順時針，一隻逆時針。一隻插在板面印住的 **R23**。這列就是 GPIO23，板上沒有 P23 這個印。另一隻插 **P5**。

| 舵機 | 黃色信號 | 紅色 | 黑色 |
| --- | --- | --- | --- |
| SG90（A） | R23 黃色（GPIO23） | R23 紅色 5V | R23 黑色 GND |
| SG90（B） | P5 黃色（GPIO5） | P5 紅色 5V | P5 黑色 GND |

有 S 時，R23 嗰隻去 180°，P5 嗰隻去 0°。連續 3 次掃描（約 0.6 秒）都冇 S，先調轉返轉頭。P34、P35 只可以輸入，唔可以做舵機信號。開機第一行 debug 應見到 `servo23+5rev` 同 `lamp18+19`。

## 上傳

```bash
git checkout gp5
pio run -t upload --upload-port 上次成功的USB埠
```

Mac 上列出埠：

```bash
ls /dev/cu.usb*
```

序列埠監視是 115200。開機應見到 `calibrating. keep magnets away`，以及 `idle` 後面 7 粒靜止電壓。
