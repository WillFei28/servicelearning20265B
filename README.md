# Gp1 鐵路平交道

這份是 `gp1`。只接下面的零件，腳位跟這份，唔好抄另一組或 `main`。

板：ESP32-WROOM-32 38-pin，插在 Goouuu ESP32S 38P 擴展板。  
上傳線插 **ESP32 模組本身的 Micro-USB**。擴展板的 USB 同 DC 座只供電，傳唔到程式。

程式是六組共用的。這組只接霍爾同埋一隻舵機。沒有接的燈、喇叭、畫面、讀卡器不會動。序列埠仍可能印 `snd` 或 `card`。

## 零件

| 零件 | 數量 | 備註 |
| --- | --- | --- |
| ESP32-WROOM-32 38-pin | 1 | 已插在擴展板 |
| Goouuu ESP32S 38P 擴展板 | 1 | 跳線撥在 5V |
| 74HC4051 | 1 | Y7 留空 |
| 49E | 7 | OUT 接 Y0–Y6 |
| SG90 | 1 | 只接 R23 |
| 杜邦線 | 若干 | |

這組沒有：燈帶 MOSFET、MAX98357A、第二隻 SG90、RC522、OLED、第 8 粒 49E、18650。

## 這組點運作

開機時附近唔好有磁鐵。程式記住 7 粒霍爾各自的靜止電壓。某一粒同自己的靜止電壓相差 **250 mV** 或以上就算有磁鐵：電壓下跌是 **N**，電壓上升是 **S**。

| 情況 | SG90（R23） |
| --- | --- |
| 無 S | 0° |
| 有 S | 90° |

N 不會郁這隻舵機。

## 接線

擴展板跳線撥在 **5V**。每一列紅色針都是 5V，黑色針是 GND，黃色針先是 GPIO。

紅色 5V 唔好接 74HC4051 或 49E。

### 74HC4051 同 7 粒 49E

`Y7` 留空。七粒 49E 的 OUT 接 Y0–Y6。有字一面向外。

| 74HC4051 | 接到 |
| --- | --- |
| S0 | P12 黃色（GPIO12） |
| S1 | P14 黃色（GPIO14） |
| S2 | P27 黃色（GPIO27） |
| Z | P35 黃色（GPIO35） |
| E | P27 黑色 GND |
| VCC | 最邊的 3.3V |
| VEE | 最邊 3.3V 下面的黑色 GND |
| GND | SD2 黑色 GND |

VEE 是負電源，必須接地。接到 3.3V 會反接電源。靠中那粒 3.3V 這組留空。

49E 供電，兩種都可以：

- VCC 由 4051 的 VCC 腳取出，GND 由 4051 的 GND 腳取出。
- 擴展板不夠位、要由另一塊板取 3.3V 和 GND：另一塊板的 GND 必須接到 4051 的 GND（SD2 黑色）。只共地。不要把兩塊板的 3.3V 並在一起。

沒有磁石時，每粒應停在大約 1500–1700 mV。讀數在 0 和 3300 mV 之間滑，是地線未共。

### SG90

只接一隻，插在板面印住的 **R23**。這列就是 GPIO23，板上沒有 P23 這個印。P5 留空。程式仍會驅動 P5，所以 P5 不要改接別的東西。

| 舵機 | 黃色信號 | 紅色 | 黑色 |
| --- | --- | --- | --- |
| SG90 | R23 黃色（GPIO23） | R23 紅色 5V | R23 黑色 GND |

有 S 去 90°，無 S 返 0°。P34、P35 只可以輸入，唔可以做舵機信號。

## 上傳

```bash
git checkout gp1
pio run -t upload --upload-port 上次成功的USB埠
```

Mac 上列出埠：

```bash
ls /dev/cu.usb*
```

序列埠監視是 115200。開機應見到 `calibrating. keep magnets away`，以及 `idle` 後面 7 粒靜止電壓。第一行 debug 有 `servo23+5`，這組只接 R23。
