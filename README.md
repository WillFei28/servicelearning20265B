# Gp6 鐵路平交道

這份是 `gp6`。只接下面的零件，腳位跟這份，唔好抄另一組或 `main`。

板：ESP32-WROOM-32 38-pin，插在 Goouuu ESP32S 38P 擴展板。  
上傳線插 **ESP32 模組本身的 Micro-USB**。擴展板的 USB 同 DC 座只供電，傳唔到程式。

程式是六組共用的。這組接霍爾、喇叭、讀卡器同 OLED。沒有接的燈帶和舵機不會動。序列埠仍可能印 `off` 或 `servo0`。

## 零件

| 零件 | 數量 | 備註 |
| --- | --- | --- |
| ESP32-WROOM-32 38-pin | 1 | 已插在擴展板 |
| Goouuu ESP32S 38P 擴展板 | 1 | 跳線撥在 5V |
| 74HC4051 | 1 | Y7 留空 |
| 49E | 7 | OUT 接 Y0–Y6 |
| MAX98357A | 1 | GAIN、SD 留空 |
| 喇叭 | 1 | 接模組喇叭端子 |
| RC522 | 1 | 只可以接 3.3V |
| SSD1306 OLED 0.96 吋 128×64 | 1 | I2C 位址 0x3C |
| 杜邦線 | 若干 | |

這組沒有：燈帶 MOSFET、SG90、第 8 粒 49E、18650。

## 這組點運作

開機時附近唔好有磁鐵。程式記住 7 粒霍爾各自的靜止電壓。某一粒同自己的靜止電壓相差 **250 mV** 或以上就算有磁鐵：電壓下跌是 **N**，電壓上升是 **S**。

| 情況 | OLED | 喇叭 |
| --- | --- | --- |
| 無磁鐵 | 空白 | 停 |
| 有 N | 大剔號 | 停，除非同時有 S |
| 有 S | 大交叉 | 循環播平交道聲 |
| N 同 S 一齊 | 交叉同剔號一齊 | 循環播平交道聲 |

最近一次有效的 N 或 S 會記住，磁鐵拿走都保留。拍 RFID 卡就用這筆記錄，用完即刻清走。清走之後，要先回到無磁鐵，先可以再記新一次。

| 記住的極 | 畫面（至少約 2.2 秒；聲音更長就播完先收） | 聲音 |
| --- | --- | --- |
| N | `+$2.0` | `audio/octopus.mp3` |
| S | `-$2.0` | `audio/error.mp3` |
| 無記錄 | 無車費畫面 | 無聲 |

幾粒同時有磁鐵時，車費記錄用相差最大的那一粒。

## 接線

擴展板跳線撥在 **5V**。每一列紅色針都是 5V，黑色針是 GND，黃色針先是 GPIO。

紅色 5V 唔好接 RC522、74HC4051 或 49E。

### 74HC4051 同 7 粒 49E

`Y7` 留空。七粒 49E 的 OUT 接 Y0–Y6。有字一面向外。

| 74HC4051 | 接到 |
| --- | --- |
| S0 | P12 黃色（GPIO12） |
| S1 | P14 黃色（GPIO14） |
| S2 | P27 黃色（GPIO27） |
| Z | P35 黃色（GPIO35） |
| E | P27 黑色 GND |
| VCC | 最邊的 3.3V |
| VEE | 最邊 3.3V 下面的黑色 GND |
| GND | SD2 黑色 GND |

VEE 是負電源，必須接地。接到 3.3V 會反接電源。最邊這粒 3.3V 只供 4051。靠中那粒 3.3V 只供 RC522。

49E 供電，兩種都可以：

- VCC 由 4051 的 VCC 腳取出，GND 由 4051 的 GND 腳取出。
- 擴展板不夠位、要由另一塊板取 3.3V 和 GND：另一塊板的 GND 必須接到 4051 的 GND（SD2 黑色）。只共地。不要把兩塊板的 3.3V 並在一起。

沒有磁石時，每粒應停在大約 1500–1700 mV。讀數在 0 和 3300 mV 之間滑，是地線未共。

### MAX98357A 喇叭

`GAIN` 同 `SD` 留空。

| MAX98357A | 接到 |
| --- | --- |
| LRC | P17 黃色（GPIO17） |
| BCLK | P16 黃色（GPIO16） |
| DIN | P4 黃色（GPIO4） |
| VIN | P4 紅色 5V |
| GND | P4 黑色 GND |
| 喇叭兩端 | 模組的喇叭端子 |

### 0.96 吋 SSD1306（128×64，I2C 位址 0x3C）

程式用 `Wire.begin(22, 21)`。

| OLED | 擴展板 |
| --- | --- |
| VCC | VCC |
| GND | GND |
| SCL | D21（GPIO21） |
| SDA | D22（GPIO22） |

### RC522 RFID

**只可以接 3.3V。** `IRQ` 留空。P35 黃色是霍爾的 Z，唔好當讀卡器腳。

P34 同 P35 都只入唔出，所以 RST 唔可以放喺呢兩隻。RST 用 P32 黃色。

| RC522 | 接到 |
| --- | --- |
| 3.3V | 靠中的 3.3V |
| GND | 該 3.3V 下面的黑色 GND |
| RST | P32 黃色（GPIO32） |
| SDA / SS | P26 黃色（GPIO26） |
| SCK | P33 黃色（GPIO33） |
| MOSI | P25 黃色（GPIO25） |
| MISO | P34 黃色（GPIO34） |

## 三個音效可以換

建置前 `embed_crossing.py` 會把這三個檔寫進程式。唔好手改 `src/crossing_mp3.h`，那個檔每次編譯會重新產生，亦唔會入 git。

| 檔案 | 何時播 | 而家大小 |
| --- | --- | --- |
| `audio/crossing.mp3` | 有 S 就循環播 | 66830 bytes，約 3.6 秒 |
| `audio/error.mp3` | 拍卡，記錄是 S | 6882 bytes，約 0.6 秒 |
| `audio/octopus.mp3` | 拍卡，記錄是 N | 7404 bytes，約 0.5 秒 |

換檔時：

1. 檔名保持 `crossing.mp3`、`error.mp3`、`octopus.mp3`。
2. 用普通 MP3。三個檔聲量盡量接近，太細會聽唔到。
3. 檔案開頭唔好帶 ID3 封面或標籤。而家三個穩定檔一開始就是 MP3 音訊框（`FF FB`）。前面如果有標籤，拍卡聲會慢一拍。
4. 只改 `gp6`，唔好直接改 `main`。

## 上傳

```bash
git checkout gp6
pio run -t upload --upload-port 上次成功的USB埠
```

Mac 上列出埠：

```bash
ls /dev/cu.usb*
```

序列埠監視是 115200。開機應見到 `calibrating. keep magnets away`，以及 `idle` 後面 7 粒靜止電壓。讀卡器正常時會見到 `rfid ok`。
