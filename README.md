# Gp4 鐵路平交道

這份是 `gp4`。只接下面的零件，腳位跟這份，唔好抄另一組或 `main`。

板：ESP32-WROOM-32 38-pin，插在 Goouuu ESP32S 38P 擴展板。  
上傳線插 **ESP32 模組本身的 Micro-USB**。擴展板的 USB 同 DC 座只供電，傳唔到程式。

程式是六組共用的。這組接霍爾、燈帶、喇叭，再加一粒不經 4051 的 49E。沒有接的舵機、畫面、讀卡器不會動。序列埠仍可能印 `servo` 或 `card`。

## 零件

| 零件 | 數量 | 備註 |
| --- | --- | --- |
| ESP32-WROOM-32 38-pin | 1 | 已插在擴展板 |
| Goouuu ESP32S 38P 擴展板 | 1 | 跳線撥在 5V |
| 74HC4051 | 1 | Y7 留空 |
| 49E | 7 | OUT 接 Y0–Y6 |
| 49E | 1 | 第 8 粒，信號獨立接 P34，唔接 Y7 |
| MOSFET 燈帶模組 | 1 | 信號接 P18 |
| 燈帶 | 1 | 經 MOSFET 開關 |
| MAX98357A | 1 | GAIN、SD 留空 |
| 喇叭 | 1 | 接模組喇叭端子 |
| 杜邦線 | 若干 | |

這組沒有：SG90、RC522、OLED、18650。

## 這組點運作

開機時附近唔好有磁鐵。程式記住多工器上 7 粒霍爾各自的靜止電壓。某一粒同自己的靜止電壓相差 **250 mV** 或以上就算有磁鐵：電壓下跌是 **N**，電壓上升是 **S**。

| 情況 | 燈帶（GPIO18 MOSFET） | 喇叭 |
| --- | --- | --- |
| 無磁鐵 | 熄 | 停 |
| 有 N | 長亮。有 N 就優先過 S | 停 |
| 有 S | 每秒閃 2 下 | 循環播平交道聲 |
| N 同 S 一齊 | 長亮 | 循環播平交道聲 |

第 8 粒已經接上，程式而家仍然只掃描 Y0–Y6。序列埠的 `1` 到 `7` 不是這粒。這組沒有讀卡器，聽得到的是有 S 時的 `audio/crossing.mp3`。

## 接線

擴展板跳線撥在 **5V**。每一列紅色針都是 5V，黑色針是 GND，黃色針先是 GPIO。

紅色 5V 唔好接 74HC4051 或 49E。

### 燈帶 MOSFET

| 位置 | 接到 |
| --- | --- |
| PWM 信號 | P18 黃色（GPIO18） |
| 模組 `+` | P18 紅色 5V |
| 模組 GND | P18 黑色 GND |
| 模組 `−` | P19 黑色 GND |
| 燈帶黑色 | 模組 LOAD |
| 燈帶紅色 | P19 紅色 5V |

P19 黃色（GPIO19）冇用。N 長亮，S 每秒閃 2 下，無磁鐵熄滅。

### 74HC4051 同 7 粒 49E

`Y7` 留空。頭七粒 49E 的 OUT 接 Y0–Y6。有字一面向外。

| 74HC4051 | 接到 |
| --- | --- |
| S0 | P12 黃色（GPIO12） |
| S1 | P14 黃色（GPIO14） |
| S2 | P27 黃色（GPIO27） |
| Z | P35 黃色（GPIO35） |
| E | P27 黑色 GND |
| VCC | 最邊的 3.3V |
| VEE | 最邊 3.3V 下面的黑色 GND |
| GND | SD2 黑色 GND |

VEE 是負電源，必須接地。接到 3.3V 會反接電源。最邊這粒 3.3V 只供 4051 同頭七粒。

49E 供電，兩種都可以：

- VCC 由 4051 的 VCC 腳取出，GND 由 4051 的 GND 腳取出。
- 擴展板不夠位、要由另一塊板取 3.3V 和 GND：另一塊板的 GND 必須接到 4051 的 GND（SD2 黑色）。只共地。不要把兩塊板的 3.3V 並在一起。

沒有磁石時，每粒應停在大約 1500–1700 mV。讀數在 0 和 3300 mV 之間滑，是地線未共。

### 第 8 粒 49E

唔接 Y7。信號、電源、地線都用獨立針，唔經 4051。

| 第 8 粒 49E | 接到 |
| --- | --- |
| OUT | P34 黃色（GPIO34） |
| VCC | 靠中的 3.3V |
| GND | 該 3.3V 下面的黑色 GND |

P34 只可以輸入。這組沒有 RC522，P34 不要改接讀卡器。

### MAX98357A 喇叭

`GAIN` 同 `SD` 留空。

| MAX98357A | 接到 |
| --- | --- |
| LRC | P17 黃色（GPIO17） |
| BCLK | P16 黃色（GPIO16） |
| DIN | P4 黃色（GPIO4） |
| VIN | P4 紅色 5V |
| GND | P4 黑色 GND |
| 喇叭兩端 | 模組的喇叭端子 |

## 音效可以換

建置前 `embed_crossing.py` 會把檔案寫進程式。唔好手改 `src/crossing_mp3.h`，那個檔每次編譯會重新產生，亦唔會入 git。

這組會播到的是 `audio/crossing.mp3`（有 S 就循環播，66830 bytes，約 3.6 秒）。`audio/error.mp3` 同 `audio/octopus.mp3` 要拍卡先播，這組沒有讀卡器。

換檔時：

1. 檔名保持 `crossing.mp3`。
2. 用普通 MP3。聲量太細會聽唔到。
3. 檔案開頭唔好帶 ID3 封面或標籤。穩定檔一開始就是 MP3 音訊框（`FF FB`）。前面如果有標籤，聲音會慢一拍。
4. 只改 `gp4`，唔好直接改 `main`。

## 上傳

```bash
git checkout gp4
pio run -t upload --upload-port 上次成功的USB埠
```

Mac 上列出埠：

```bash
ls /dev/cu.usb*
```

序列埠監視是 115200。開機應見到 `calibrating. keep magnets away`，以及 `idle` 後面 7 粒靜止電壓。第 8 粒不會出現在這行。
